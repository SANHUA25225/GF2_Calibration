GF-2 辐射定标程序 · 操作指南

这个程序做什么？
把 GF-2 卫星的原始影像（DN 灰度值）换算成有物理意义的辐射亮度，公式为： Radiance = Gain × DN + Offset。定标系数会自动从影像配套的 XML 元数据（<AbsCeof> 标签）中读取，不需要手动输入。 结果以 BIP 存储方式保存为 GeoTIFF（LZW 压缩），ENVI / ArcGIS / QGIS 都能打开。

二、怎么运行

方式 A：双击运行（推荐，零命令）

1打开 D:\GF2_Calibration 文件夹
2双击 运行定标.bat，会弹出黑色命令行窗口并自动开始
3等待 1～3 分钟，看到 [完成] 辐射定标结果已保存 即成功，按任意键关闭窗口

方式 B：手动命令行（备用）

1按 Win 键，输入 Anaconda Prompt 回车，打开命令行窗口
2输入 conda activate gf2obia 回车（行首出现 (gf2obia) 即成功）
3粘贴下面一行，回车： 
python "D:\GF2_Calibration\gf2_radiometric_calibration_fixed.py"

四、换一景影像怎么办

1右键 输入配置.txt → 打开方式 → 记事本
2把 = 右边改成新影像的路径（共 3 处，见下表）
3保存（Ctrl+S），再双击 运行定标.bat 即可
要改的行= 右边填什么
INPUT_IMAGE新影像的 ...-MSS1.tiff 完整路径
XML_PATH同目录下配套的 ...-MSS1.xml 完整路径（必须一起换，否则系数不对）
OUTPUT_IMAGE输出结果想存的位置和文件名

提示：路径直接粘贴即可，不需要加引号；以 # 开头的说明行不用动。定标系数会自动从新影像的 XML 读取。

五、常见问题

现象原因与解决
双击 .py 文件闪退正常现象——直接双击用的不是 conda 环境。请用 运行定标.bat 或方式 B。
[错误] 找不到输入文件配置区 INPUT_IMAGE 路径写错了，检查盘符、文件名是否一致。
系数个数与波段数不一致换用全色影像（1 波段）但系数是 4 波段的。全色数据请改配置区 GAINS 为 1 个值，或告诉我帮你改。
输出文件很大 / 打不开输出约 0.8～1 GB（float32 + LZW），属正常；确认 D 盘剩余空间充足。
影像没有地理坐标GF-2 L1A 原始数据本身不带投影，属正常。需要配准/正射时用影像自带的 .rpb 文件在 ENVI/GDAL 中处理。
注意：输出默认保存到 D:\gf2\GF2_MSS_Radiance_BIP.tif，重复运行会覆盖上次结果；想保留就先改 OUTPUT_IMAGE 文件名。
